How does Redux works ?
Redux ese kaam karta hai ki , ki hum ek store banate hai and then alag-alag bahut saare custom defined Slices banate hai . And then hum wo slices nahi balki slices ke bane reducers ko store se connect kar dete hai yaani hum un reducers ko store me daal dete hai .Ese hi hum bahut saare alag-alag kaam karne wale slices ko tyyar kar lete hai and unke reducers ko store me daal dete hai .Now, uske baad sabhi components us store ko access kar sake toh hum Pure </App> ko hi store me wrap kar dete hai . Now ab redux hume do methods deta hai 1st is useDispatch and useSelector . Toh ab pura flow kaise work karta hai ki like when we click on button toh useDispatch ek function ko as its parameter leta hai and useDispatch ka kaam kya hota hai ki wo kya karta hai ki wo ek query bhejta hai redux store ke paas jise hum event dispatch hona kehte hai and us query me store ko bola jaata hai ki Is reducer(function) ko run kar dena . Store yeh request accept kar leta hai and jis slice me yeh reducer present hai us slice ko bolta hai ki is reducer ko run karo and then wo reducer waha run hota hai and waha jo initialStage naam ka variable hota hai uski value change kar deta hai ya we can say it changes the state . And agar humne useSelector ka use karke us initialStage ki value ko pakda hoga apne main code me and kahi use kiya hoga toh waha bhi uski value change ho jaati hai . This is how we use Redux .

Shortform concept:
Make slices -> connect slices with store -> give components access to store -> and then when click on button -> Event Handler Run -> EventDispatch as useDispatch used -> Request reaches store -> Store transfer request to that specific slice which has that reducer and then reducers runs in that slice -> And then initialStage changes -> And because that variable is used in main file -> Hence there also the value or state changes and visible to us on viewport -> This is redux.
